## Getting Started

### Prerequisites
Make sure you have [uv](https://docs.astral.sh/uv/) and Python 3.13+ installed.

### Setup and Run
1. Clone the repository:
   ```bash
   git clone https://github.com/muhammadmaroof11/python-ai.git
   cd python-ai
   ```
2. Sync dependencies:
   ```bash
   uv sync
   ```
3. Run the main entry point:
   ```bash
   uv run main.py
   ```
